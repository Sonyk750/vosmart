Un raport al cenzorului asociației de proprietari își face treaba doar dacă recomandările din el sunt duse la capăt. Cel mai simplu mod de a face asta este un **tabel de urmărire a recomandărilor**: fiecare observație primește un responsabil, un termen și o stare, iar comitetul îl parcurge la fiecare ședință. Mai jos găsești un model orientativ, gata de copiat, și explicația fiecărei coloane.

Documentul este util oricărei asociații, indiferent dacă verificarea o face un cenzor individual sau o firmă de cenzorat. VoSmart, firmă de cenzorat din București care lucrează cu asociații din toată România, folosește aceeași logică: constatarea fără termen și fără responsabil nu schimbă nimic.

## De ce nu ajunge raportul singur

Raportul spune ce s-a găsit. Remedierea depinde de comitet și de administrator. În practică se întâmplă frecvent ca:

- recomandarea să fie citită în adunarea generală și apoi uitată;
- la raportul următor aceeași observație să apară din nou, identică;
- nimeni să nu știe cine trebuia să facă ce.

Dacă ai citit [modelul complet de raport de cenzor](/blog/raportul-de-cenzor-model-complet-2026), știi că recomandările sunt o secțiune distinctă. Tabelul de mai jos este continuarea ei practică.

## Modelul de tabel (model orientativ)

Copiază structura într-o foaie de calcul sau într-un document al asociației.

| Nr. | Data raportului | Constatarea | Recomandarea cenzorului | Responsabil | Termen | Stare | Dovada remedierii | Observații |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | Deschis / În lucru / Închis | | |
| 2 | | | | | | | | |
| 3 | | | | | | | | |

> Model orientativ. Adaptează-l la nevoile asociației și la regulile din regulamentul propriu. Nu înlocuiește raportul cenzorului și nu are valoare juridică de sine stătătoare.

### Cum completezi fiecare coloană

1. **Nr.** – număr de ordine, constant de la un raport la altul, ca să poți urmări o observație în timp.
2. **Data raportului** – raportul în care a apărut constatarea.
3. **Constatarea** – formulată concret: ce document, ce perioadă, ce sumă. „Gestiunea e neclară” nu e o constatare utilă; „chitanța din luna martie nu are număr” este.
4. **Recomandarea cenzorului** – exact ce propune cenzorul, copiat din raport.
5. **Responsabil** – o persoană, nu „comitetul”. De regulă administratorul, casierul sau președintele.
6. **Termen** – o dată calendaristică, nu „cât mai curând”.
7. **Stare** – trei valori sunt suficiente: deschis, în lucru, închis.
8. **Dovada remedierii** – documentul care arată că problema s-a rezolvat: o chitanță corectată, o decizie, un extras.
9. **Observații** – motive de amânare, discuții cu cenzorul.

## Exemple de rânduri completate

| Nr. | Constatarea | Recomandarea | Responsabil | Termen | Stare |
|---|---|---|---|---|---|
| 1 | Registrul de casă nu este completat zilnic în ultimele două luni | Completare la zi și semnare lunară de către casier și președinte | Casier | 15.12.2026 | În lucru |
| 2 | Două facturi de furnizori lipsesc din dosar | Obținerea duplicatelor și atașarea lor la lista de plată | Administrator | 30.11.2026 | Deschis |
| 3 | Fișa de reconciliere cu extrasul nu s-a făcut pe ultima lună | Reconciliere lunară, fișă atașată raportului | Administrator | Lunar | Închis |

Pentru ultimul exemplu, cenzorul poate folosi [fișa de reconciliere cu extrasul bancar](/blog/cum-verifica-cenzorul-contul-bancar-al-asociatiei-model-fisa), iar pentru primul [modelul de verificare a casieriei](/blog/verificarea-casieriei-asociatiei-de-proprietari).

## Cum îl folosești, pas cu pas

1. După primirea raportului, comitetul trece fiecare recomandare în tabel în maximum câteva zile.
2. Responsabilii confirmă termenele realiste. Un termen asumat contează mai mult decât unul impus.
3. La fiecare ședință a comitetului, tabelul este primul punct pe ordinea de zi.
4. Când o recomandare e remediată, se atașează dovada și starea devine „închis”.
5. Cenzorul primește tabelul actualizat la următoarea verificare și confirmă sau nu închiderea.
6. Observațiile rămase deschise se prezintă în adunarea generală, împreună cu motivul.

Așa cum se arată și în articolul despre [rolul cenzorului în adunarea generală](/blog/adunarea-generala-si-rolul-cenzorului), proprietarii au nevoie să vadă nu doar problemele, ci și ce s-a făcut cu ele.

## Ce faci când o recomandare nu este respectată

Dacă termenul trece și nu există nicio dovadă:

- consemnezi în tabel motivul declarat;
- ceri o nouă dată, aprobată de comitet;
- dacă situația se repetă sau suma e importantă, urmezi pașii din [ghidul despre suspiciuni de nereguli](/blog/suspiciuni-de-nereguli-in-asociatie).

Legea 196/2018 reglementează rolul cenzorului și al organelor asociației; pentru situații concrete, consultă textul legii sau un specialist.

## Cine ține tabelul

Cel mai bine funcționează dacă îl ține o singură persoană din comitet, de regulă secretarul sau președintele, nu cenzorul. Cenzorul verifică, comitetul execută: păstrarea celor două roluri separate protejează independența controlului. Dacă administrarea este făcută de o firmă separată, precum [DecoImob](https://decoimob.ro) (firmă de administrare imobile, independentă de VoSmart), administratorul primește tabelul ca parte a relației normale cu comitetul. Pentru o pagină de prezentare a serviciului de verificare, vezi [cenzorat asociații](https://www.vosmart.ro/cenzorat-asociatii).

## Intrebari frecvente

**Ce este un tabel de urmărire a recomandărilor cenzorului?**
Este un document intern în care fiecare observație din raportul cenzorului primește un responsabil, un termen, o stare și o dovadă a remedierii. Ajută comitetul să nu piardă recomandările între rapoarte.

**Este obligatoriu acest tabel?**
Nu. Este o practică utilă, nu o cerință din lege. Obligația cenzorului de a raporta rămâne cea din legislație, iar tabelul doar ajută la punerea în practică a recomandărilor.

**Cine completează tabelul, cenzorul sau comitetul?**
Constatările și recomandările vin din raportul cenzorului, iar responsabilii, termenele și dovezile le completează comitetul. Separarea păstrează independența cenzorului.

**La ce interval se actualizează?**
Cel mai potrivit este la fiecare ședință a comitetului și înainte de fiecare nou raport al cenzorului.

**Pot folosi tabelul și dacă cenzorul este o firmă?**
Da. Modelul funcționează la fel indiferent dacă verificarea o face un cenzor individual sau o firmă de cenzorat; firma primește tabelul actualizat la următoarea verificare.
